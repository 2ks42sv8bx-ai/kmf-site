Install

KOReader. Install it with its guide. Unzip the plugin into its plugins folder. Open Menu, Tools, vandenHove, Account, and enter the code you were given.

Obsidian. Unzip the plugin into your vault's .obsidian/plugins folder, and turn it on in Settings, Community plugins. Open Settings, vandenHove, and enter the code from KOReader's Account menu, under Code for another device.

Sharing. On your e-reader, tap a highlight, tap the three dots (…), then Share with groups.
