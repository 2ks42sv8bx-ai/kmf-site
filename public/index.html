vandenHove Setup guide Groups

Setup guide

  1. 1

    Install KOReader

    Plug in your Kobo and run the installer.

    Follow KOReader's steps.

  2. 2

    Add the plugin

    Unzip vandenhove.koplugin into KOReader's plugins folder.

  3. 3

    Enter your code

    Menu, Tools, vandenHove, Account.

  4. 4

    Connect Obsidian

    Unzip the plugin into your vault's .obsidian/plugins folder, and turn it on. Get a second code from your e-reader's Account menu.
